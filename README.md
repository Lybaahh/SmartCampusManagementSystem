Smart University Campus Management System

Overview

The Smart University Campus Management System is a Java-based desktop application developed as an Object-Oriented Programming (OOP) project. The system manages academic units, facilities, service units, courses, students, and campus zones through an interactive graphical user interface.

Features
- Role-based access (Admin, Teacher, Student)
- Student management
- Course management
- Academic unit management
- Facility management
- Service unit management
- Campus zone management
- Statistics and report generation
- Medical emergency support
- Class rescheduling functionality
- Data persistence using file handling
- Interactive Java Swing GUI

Object-Oriented Concepts Implemented
- Classes and Objects
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Interfaces
- Composition
- Aggregation
- Generics
- Exception Handling

Technologies Used
- Java
- Java Swing
- Object-Oriented Programming
- File Handling (Serialization)
- Collections and Generics

Project Structure
- CampusEntity
- AcademicUnit
- Facility
- ServiceUnit
- Department
- Course
- Student
- Assignment
- CampusZone
- CampusRepository
- FileHandler
- CampusManagementGUI

Academic Purpose

Developed as an Object-Oriented Programming course project to demonstrate practical implementation of OOP principles, GUI development, and file handling in Java.
